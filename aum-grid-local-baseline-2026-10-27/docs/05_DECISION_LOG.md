This ledger keeps accepted decisions, working hypotheses and deferred ideas separate. It does not claim the user approved anything beyond what was explicitly decided during the study.

## Working hypotheses, not final decisions

| Hypothesis | What would validate or disprove it? |
| --- | --- |
| International is the safer commercial foundation | First-impression trust, task clarity, scalability and maintainability comparisons |
| Elevation has more distinct personality | Recognition/recall, local-context and property-detail comprehension tasks |
| Eight near-equal routes create choice overload | Compare grouped-versus-equal homepage variants with first-click tasks |
| Property cards need more structured, verified information | Evaluation task performance and confidence before enquiry |
| An accurate neighbourhood atlas improves trust | Real locality comprehension and advice outcomes |
| Fourth color adds material richness | Blind, baseline-controlled design comparison without CTA confusion |
| Controlled dimensionality improves affordance | Flat-versus-relief tasks, touch/keyboard and performance checks |

## Deferred until evidence and data support them

- Final font/palette lock for production.
- A fully developed property detail system.
- Live listings/CRM integration.
- Rich location profiles, maps and geographic data.
- Interactive building/plan visualization.
- Saved properties or compare functionality.
- Structured listing-owner intake.
- A/B testing on genuine production traffic.

Deferral is not rejection. Build these only when the product requirement, source data and test plan are clear.

## Rejected or constrained ideas

- Generic stock skyscraper illustration as the site's main character.
- Random gradients, glossy cards, glowing edges and AI-slop motifs.
- More colors simply because more colors are available.
- Constant movement, tilted/rotating 3-D cards and scroll-jacking.
- Hover-exclusive navigation information.
- Fake dimensions, placeholder floor plans, invented prices, unsupported returns and testimonials.
- Changing live `aumestates.com` while still experimenting privately.

## Process decision for the next chat

**Paired incremental releases:** shared R0, then I1/E1, I2/E2, … I6/E6. Keep facts and functionality equal for both; test the architectural treatment separately from improvements to underlying customer journeys.

**Recommendation:** Continue both through the property-detail stage (R3), unless an earlier test exposes a decisive usability failure. Do not merge their expression prematurely.
